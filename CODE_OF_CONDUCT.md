# AlternativeCAM Code of Conduct

AlternativeCAM is a maker and CNC community project.

Please:

- Treat users and contributors respectfully.
- Keep technical disagreements focused on the work rather than the person.
- Provide constructive feedback.
- Help newer users when possible.
- Avoid harassment, discrimination, threats, or deliberately disruptive behavior.
- Respect the project's license and contribution guidelines.

GabrielMaker reserves the right to moderate project spaces when necessary to keep discussion productive and welcoming.
